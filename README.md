# ⚔️ Reich der Zeitalter

Ein Strategiespiel im Stil von **Age of Empires 2** – gemacht fürs **Smartphone**.
Aufbauen, Armee ausbilden, durch die Zeitalter aufsteigen und die feindliche
Festung zerstören – **gewinnen oder verlieren**.

Das ganze Spiel steckt in einer einzigen Datei (`index.html`) und läuft direkt
im Browser. Keine Installation, kein App-Store.

## 📱 So spielst du es auf dem Handy

**Variante A – Kostenlos online (empfohlen):**
1. Aktiviere GitHub Pages für dieses Repo:
   *Settings → Pages → Branch:* `claude/smartphone-aoe-game-0eq80u` *→ Save.*
2. Nach ein paar Minuten erreichst du das Spiel unter
   `https://<dein-name>.github.io/game/` – einfach im Handy-Browser öffnen.
3. Tipp: Im Browser auf „Zum Home-Bildschirm hinzufügen“ – dann startet es wie
   eine echte App im Vollbild.

**Variante B – Datei direkt:**
- Schicke dir die Datei `index.html` (z. B. per Mail/Messenger) aufs Handy und
  öffne sie im Browser.

## 🎮 Spielprinzip

- **🧑‍🌾 Dorfbewohner** sammeln automatisch Nahrung 🍖, Holz 🪵 und Gold 🪙.
  Je mehr du hast, desto schneller wächst deine Wirtschaft.
- **⚔️ Soldaten, 🏹 Bogenschützen, 🐎 Ritter, 💥 Kanonen** marschieren
  automatisch los und greifen den Feind an.
- **🗼 Wachtürme** verteidigen deine Burg gegen anrückende Gegner.
- **🛠️ Reparieren** stellt die Lebenspunkte deiner Burg wieder her.
- **⌛ Zeitalter-Aufstieg** (Dunkles Zeitalter → Feudalzeit → Ritterzeit →
  Imperialzeit) macht alle Einheiten stärker und schaltet neue frei.

**Ziel:** Zerstöre die feindliche Festung 🏯, bevor sie deine Burg 🏰 zerstört.

## 💡 Tipps

- Baue zuerst ein paar **Dorfbewohner** für die Wirtschaft, bevor du Soldaten
  ausbildest.
- Halte ein paar **Türme** zur Verteidigung, während du eine Armee aufbaust.
- **Bogenschützen** und **Kanonen** kämpfen aus der Distanz – stark in Gruppen.
- Steige im **Zeitalter** auf, sobald du es dir leisten kannst – das ist der
  größte Machtschub.

Drei Schwierigkeitsgrade: **Leicht / Normal / Schwer**.
